Local SMS Desktop App

Extract and export iPhone Messages conversation history locally. Nothing leaves your Mac.

Before you start

You choose the files — the app only reads what you select.

  1. Locate the chat.db file you want to convert.
  2. If macOS protects the original Messages database, copy chat.db to another folder first.
  3. Select that database and load contacts.
  4. Select a contact and export XML locally.

1. Find your Messages database

Choose the exact chat.db file you want to convert, or use Browse DB folder in the left menu.
