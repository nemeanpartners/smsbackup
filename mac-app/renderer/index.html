Before you start

The App Store version uses the standard macOS file picker. You choose the files, and the app only reads what you select.

  1. Locate the chat.db file you want to convert.
  2. If macOS protects the original Messages database, copy chat.db to another folder first.
  3. Select that database in this app and load contacts.
  4. Select a contact.
  5. The app exports XML locally.
  6. Nothing is uploaded by this app.
